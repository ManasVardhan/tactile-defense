# References

The research notes in this folder were written from publicly available material about
the original 2015 game.

The reference screenshots and video frames that these notes cite by filename
(`playstore/ps_*.png`, `video_frames/f_*.jpg`) and the side-by-side comparison images
(`Docs/Comparisons/*.png`) are third-party copyrighted material. They were used for
private study only and are intentionally not included in this repository, so image
links to those paths in the documents will not resolve.
