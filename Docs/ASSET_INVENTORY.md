# Tactile Wars Recreation: Asset Inventory

Status updated 2026-11-17 against the files actually on disk (checked with `ls` and `find`). Status values used: **present** (file exists on disk), **missing** (planned, not on disk), **not implemented** (planned or named in the brief, no asset and no code). "Present" means the file exists; it does not mean it was reviewed by a human (audio in particular was never listened to). Rows marked "renamed" exist under a different path than originally planned.

Source key: **Blender script** = generated headless by a script in `Tools/blender/`; **synthesized** = generated by a script in `Tools/audio/` or procedurally by an editor script; **Unity-generated** = created by editor automation (`TactileWars.EditorTools.*`). License for every row: **original, project-owned** unless noted.
