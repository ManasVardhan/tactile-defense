# Tactile Wars Recreation: Asset Inventory

Every asset in `ARCHITECTURE_CONTRACT.md` plus the assets needed by the design docs. All statuses are **planned**; a later QA pass will update statuses against what exists on disk. Valid status values for that pass: planned, in progress, done, missing, rejected.

Source key: **Blender script** = generated headless by a script in `Tools/blender/` (the script is the source of truth, FBX exported to `Assets/`); **synthesized** = generated by a script in `Tools/audio/` or a procedural script; **Unity-generated** = created by editor automation (`TactileWars.EditorTools.*`) or authored in Unity. License for every row: **original, project-owned** unless noted.
